# TalentSkillMate AI

## AI-Powered Resume Screening & Candidate Matching System

TalentSkillMate AI is an AI-powered recruitment assistant designed to help HR professionals screen resumes, match candidates with job requirements, and generate recruiter-friendly insights.

## 🚀 Features

- 📄 PDF and DOCX resume parsing
- 🤖 AI-powered resume analysis
- 🎯 Candidate-to-job matching
- 📊 Candidate match score
- 🔍 Hidden skill discovery
- 📝 Evidence-based candidate matching
- 💡 AI-generated interview questions
- 📑 Recruiter reports
- 🏆 Candidate ranking
- 🧠 RAG-based knowledge retrieval
- 📥 Downloadable reports
- 🎨 Professional Streamlit dashboard

## 🛠️ Technologies Used

- Python
- Streamlit
- Hugging Face API
- Hugging Face LLM
- PyMuPDF
- python-docx
- ChromaDB
- RAG
- Plotly
- Pandas
